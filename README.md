# amol-nv/user_crud

This repository contains a Go service that exposes RESTful CRUD endpoints for users.

## Endpoints
- `POST /users` - create a user
- `GET /users/{id}` - get a user by id
- `PUT /users/{id}` - update a user
- `DELETE /users/{id}` - delete a user

## Running
- `go test ./...`
